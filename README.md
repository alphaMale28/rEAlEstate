# 🏠 RealEstate Platform

A modern full-stack real estate platform that allows users to list, discover, and manage properties with real-time communication, interactive maps, and secure authentication.

🔗 Live Demo: https://realestate-oh8j.onrender.com

---

## ✨ Overview

RealEstate Platform is a full-featured web application built to simulate a real-world property marketplace. It supports property listings, advanced search, real-time chat between users, and map-based discovery — all wrapped in a clean, responsive UI.

---

## 🚀 Key Features

### 🔐 Authentication & Security
- Secure login/signup system using JWT authentication  
- HTTP-only cookies for safe session management  
- Protected routes with backend middleware  

### 💬 Real-Time Communication
- Built-in real-time chat system using Socket.io  
- Instant messaging between users  

### 🏡 Property Management
- Create, update, and delete property listings  
- Upload and manage images via Cloudinary  
- Full CRUD functionality for listings and user profiles  

### 🗺️ Interactive Maps
- Integrated Leaflet maps for location-based property browsing  
- Visual discovery of properties on map  

### ⚡ Frontend Experience
- Built with React + SCSS  
- Dynamic routing with React Router DOM  
- Optimized data loading for smoother UX  
- Global state management using Zustand  

### 🧠 Backend Architecture
- RESTful APIs built with Express.js  
- Prisma ORM for database management  
- MongoDB as the database  

---

## 🛠️ Tech Stack

**Frontend:** React, SCSS, React Router DOM, Zustand, Leaflet, Axios  
**Backend:** Node.js, Express.js, Prisma ORM, MongoDB, Socket.io  
**Other:** JWT Authentication, Cloudinary
